## 📌 About

E-Commerce is a web-based online shopping platform built with Laravel.

The application provides two main sides:

- 🛍️ Customer Storefront
- ⚙️ Admin Dashboard

Customers can browse products, manage their cart and wishlist, apply coupons, place orders, and manage their accounts.

Administrators can manage products, brands, orders, users, and other store data through a dedicated dashboard.
